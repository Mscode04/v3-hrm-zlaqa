# /today · My Day

**Purpose:** Daily log. People add what they actually work on, planned or unplanned, with optional time. No approval.

**Access:** Everyone with *Daily log* switched on (Employees → Edit → What we track). Managers get a **Team log** tab for their team, by date, with comments.

**Feeds:** Self-added items are `tasks` rows with `self_added = true`, `log_date`, `minutes`. They count in task completion and can drive the *Daily log entries* auto-KPI.

**Data:** `tasks`, `task_comments`. Comments notify the assignee and creator.

**Toggle:** Settings → Features → Daily log.
